# HoopFinder 🏀

HoopFinder is an iOS basketball application built with SwiftUI that helps users discover basketball courts, explore NBA teams and standings, and save their favorite locations.

## Features

- 🗺️ Interactive map for discovering basketball courts
- ⭐ Save and manage favorite courts
- 🏀 Browse NBA teams and team information
- 📊 View NBA standings
- 📍 Location-based functionality
- 📱 Native iOS interface built with SwiftUI

## Tech Stack

- Swift
- SwiftUI
- SwiftData
- MapKit
- Core Location
- MVVM Architecture
- REST API Integration

## Architecture

HoopFinder uses the MVVM (Model-View-ViewModel) architecture to separate the user interface, application logic, and data models. This keeps the project organized and makes individual components easier to maintain and expand.

## Project Structure

- **Views** - SwiftUI screens and reusable interface components
- **Models** - Basketball court and NBA team data models
- **ViewModels** - Application state and presentation logic
- **Services** - NBA API communication and external data handling
- **LocationManager** - User location and location-based functionality

## About

HoopFinder was developed as an iOS project focused on combining location-based court discovery with NBA information in a single mobile application.
